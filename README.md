# Noor Foods Order API

Noor Foods Order API is a simple RESTful API built using **FastAPI, Python, and Pydantic** to manage customer orders. It allows users to retrieve all orders, filter orders by status (pending or delivered), fetch individual orders using their order ID, and create new orders.

The project demonstrates fundamental API development concepts, including HTTP GET and POST requests, data validation, Python enums, path and query parameters, and HTTP exception handling. It uses an in-memory dictionary to store sample order data and provides interactive API documentation through FastAPI's Swagger UI at `/docs`.

### Tech Stack
- Python
- FastAPI
- Pydantic
- uv (Package Manager)
